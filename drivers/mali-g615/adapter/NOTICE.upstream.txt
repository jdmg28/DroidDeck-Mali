DroidDeck Mali-G615 experimental driver import package 0.1.0

This package requires the matching DroidDeck source patch. The official APK is
not sufficient. Import under the Linux Runtime driver, NEVER the Android
Display driver. Keep Display on Auto (system Mali Vulkan).

No root, kernel replacement or vendor driver replacement is performed.
PanVK performs the actual GPU rendering. The adapter only adds a render-node
compatibility facade for gamescope on a Mali-G615; all other GPU capabilities
are delegated. Steam/Big Picture on your stock phone has NOT been validated.

Do not disable SELinux or change /vendor libraries to try to make this work.
If the GPU hangs or the phone overheats, stop the experiment.
